# 循序 · 手机与电脑健身工作台 v2

私人手机入口：https://xunxu-fitness-workbench.easy-plume-7011.chatgpt.site

电脑入口：http://localhost:4317

## 这次修改

1. 删除 Apple 健康连接、密钥、上传接口和 XML 转换功能。保留手动输入步数、静息心率、睡眠与身体数据，已有档案不清空。
2. 增加手机网页应用：Safari 打开私人入口，登录拥有该站点的账户，点击“分享 → 添加到主屏幕”。第一次加载完成后，计划与人体 3D 指导会缓存到手机，可离线查看。不是 App Store 原生 iOS 安装包。
3. 增加“今日训练”入口。按今天排定或实际完成的动作显示指导；换练推、拉、腿之后，指导列表随之变化。休息日显示恢复说明。
4. 15 个动作全部采用 Blender 官方写实人体基础网格，配有 17 个骨骼、15,093 个顶点的蒙皮模型；可旋转、慢放、暂停及拖动关键姿势。采用真实比例人体网格，没有用火柴人、图标或卡通人物代替。
5. 完整原视频仍保存在原电脑路径；手机附有每个动作约 30 秒的原视频对照片段。片段位置见 public/clips/sources.json。片段需联网播放，不占用首次离线缓存；不需要回看完整视频即可查看 3D 与文字要点。

## 手机首次使用

- 手机与电脑各自保存档案，**不自动跨设备同步**。
- 要继续使用电脑里的计划：电脑“我的设置 → 导出档案到手机”，将 JSON 文件保存到手机“文件”，然后在手机“我的设置 → 导入电脑 / 手机档案”中选择该文件。后续手机可独立记录、排程和复盘，不依赖电脑开机。
- 没有已有档案时，直接在手机填写身体档案即可。也可以切换到独立演示档案体验。
- 手机打开后保持联网片刻，等首次资源缓存完成。首次打开、账户登录、条码数据库查询及视频对照片段需要联网；再次打开后的计划、记录和 3D 模型支持离线使用。
- 系统或浏览器可能因清理空间移除缓存和站点数据。不要把浏览器当成唯一备份；定期导出档案，体态原图另行保存。
- 私人在线入口只发布应用代码、人体模型和用户视频教学片段，不上传当前个人档案、体态照片、API 密钥或原始长视频。私人站点的访问需要拥有该站点的账户。

## 今日指导怎么用

“今日总览”中的今日训练卡 → “打开今日指导” → 选择一个动作。

- 拖动模型：旋转视角；双指缩放。
- 正面 / 侧面 / 背面 / 斜侧：快速看姿势。
- 播放 / 暂停、速度：控制重复节奏。
- 进度滑块、三个关键姿势按钮：停下来检查动作。
- 模型下方：视频强调的准备、发力、还原与代偿风险。
- 对照原视频：电脑打开完整原片的对应时间；手机打开配套片段。

这些动作是**根据视频要点制作的教学重建**，不是逐帧动捕或教练已审定的运动学标准。人物比例、器械尺寸和关节活动范围是展示参数。不要追求复刻模型的固定深度；以自身可控范围、稳定性与视频提示为准。

## 继续保留的系统

- 身体记录与 7 日均线：最近 7 个日历日至少 4 次测量才画均线，缺测不补零。
- 营养预算：手动 TDEE 或身高、年龄、体重与活动系数估计；均衡、碳水循环、低碳偏好；日程变化会重新平衡周预算。未确认饮食完整时只显示目标剩余额度。
- 训练记录：重量、次数、RPE、热身与单侧记录；工作组及同动作周度外部负重量对比。自重与辅助负重不混入外部吨位。
- 复盘：连续三周数据才能比较两段连续周均值变化；考虑记录覆盖、围度和恢复信号，建议经确认后执行。
- 韩国食材：按包装每份克数、生熟重和钠 mg 录入；Coupang 商品链接、食材库、条码查询、备餐清单。
- AI 标签识别：电脑端可自行配置兼容服务的 VISION_URL、VISION_KEY、VISION_MODEL。私人手机静态应用不存储服务密钥，目前使用手动标签或条码录入。

## 电脑重新启动

在项目目录运行 `./start.ps1`，或：

```powershell
npm install
node --env-file-if-exists=.env server.mjs
```

需要 Node.js 24。桌面服务默认只监听本机。原视频路径在本地 video-sources.json 中，移动视频后需更新。该文件不上传在线源码仓库。

## Windows 桌面版

`循序-健身工作台-2.0.0-Windows.exe` 是可直接双击打开的独立 Windows 软件，不需要先启动 Node.js 或浏览器。首次启动可能被 Windows 的未知发布者提示拦截；确认文件来自本项目后选择“仍要运行”即可。

桌面版的个人记录保存在 Windows 用户数据目录中的“循序\\data”，不在可执行文件旁边。升级或替换 EXE 不会清空记录；仍建议在“我的设置”定期导出档案。

## 源码与数据

- public/app.js：工作台交互。
- public/engine.js：训练排程、营养、趋势与复盘规则。
- public/guide-data.js：15 个动作的指导文字。
- public/human-viewer.js：真实人体骨骼、动作轨迹、相机与器械。
- public/models/training-human.glb：人体蒙皮模型。
- public/portable-store.js：手机端 IndexedDB 档案存储。
- public/sw.js、manifest.webmanifest：离线缓存与主屏幕安装。
- data/：只在电脑本地存在的个人数据，不包含在源码发布或源码压缩包中。
- .openai/hosting.json：私人站点标识与静态资源目录。

测试：`npm test`；电脑交互：`node tests/full-ui.mjs`；逐动作 3D 检查：`node tests/poses.mjs`。浏览器测试使用当前电脑的 Chrome。交互测试会重置演示档案，不修改真实档案。

源代码压缩包需要重新安装依赖；在线部署的静态应用不依赖 Node 服务。完整视频分析保存在 public/analysis.html，可在工作台内阅读。
